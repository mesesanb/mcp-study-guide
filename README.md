# MCP Study Guide
Model Context Protocol
This repository hosts a single-page HTML study guide for the Anthropic Academy course on the Model Context Protocol (MCP).

## What it's about

The guide explains the core MCP ideas in a simple, practical way for software engineers:

- Tools: model-controlled actions Claude can decide to call
- Resources: app-controlled data your application reads and injects into context
- Prompts: reusable user-triggered instruction templates
- Architecture: host, client, and server interactions
- The relationship between the MCP client and the underlying server
- How to test and debug an MCP server using the Inspector
- Common quiz-style questions and a practice quiz

The page is structured like a course study companion and includes:

- lesson-by-lesson notes
- architecture diagrams
- code examples in Python and TypeScript
- a glossary of MCP terms
- a self-test quiz
